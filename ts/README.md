# @action-state-group/capsule-viewer

capsule-viewer's offline presentation page shell and builder, rendering under
[Agent Action Capsule](https://github.com/action-state-group/agent-action-capsule)'s
presentation contract (`spec/presentation-contract-v0.md`). The Go twin is the
module `github.com/action-state-group/capsule-viewer/go`.

Releases follow [RELEASING.md](https://github.com/action-state-group/capsule-viewer/blob/main/RELEASING.md).
